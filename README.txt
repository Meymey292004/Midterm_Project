
SYSADMIN NEXUS
System Administrator Career Portfolio
======================================

PROJECT DESCRIPTION
SysAdmin Nexus is a responsive educational website designed to help
aspiring System Administrators explore certifications, develop
technical skills, and find reliable IT learning resources.

TECHNOLOGY
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub Pages (optional for publishing)

PROJECT FILES
- index.html  : Website content and sections
- style.css   : Design, colors, layouts, and responsive styling
- script.js   : Navigation, search, and certification filters
- README.txt  : Project documentation

HOW TO RUN LOCALLY
1. Create a folder named sysadmin-nexus.
2. Save all four files inside that folder.
3. Open the folder in Visual Studio Code.
4. Open index.html in a browser, or use the Live Server extension.
5. Check the navigation, search, filters, and external links.

PERSONALIZATION
Open index.html and find the About Me section.
Replace [Your Name] with your name.
Replace [Your Course / Program] with your actual course or program.
